# Strict Protocol: Curriculum Management

1. **Academic Rigor**: All learning resources MUST be of high academic quality, prioritizing MIT OpenCourseWare (OCW), Harvard CS50, freeCodeCamp, and official documentation.
2. **Immutability of Existing Curriculum**: Once a skill or roadmap node is generated and accepted by the user, it MUST NOT be changed, modified, or removed without explicit user permission.
3. **Additive Only**: The agent is permitted to add new skills or nodes to the roadmap, but never to alter the existing structure or content of established nodes.
4. **No Destructive Rebuilds**: Destructive "Rebuild" operations that wipe existing progress or structures are strictly forbidden unless explicitly requested by the user with full awareness of the consequences.
5. **Respect User Intent**: Always prioritize the user's specific learning preferences (e.g., academic depth, video-first where applicable but academic rigor is paramount).
